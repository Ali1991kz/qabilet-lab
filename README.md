## Қазіргі белсенді нұсқа: v4.1 — мұғалім оқушыны тіркейді

Мұғалім өзі логин/email және пароль таңдап тіркеледі. Сынып автоматты құрылады; ChatGPT аккаунтымен кіру немесе `teacherAccess` арқылы қолмен бекіту қажет емес. Кабинеттегі **Оқушыларды тіркеу** беті оқушының аты, логині, бастапқы паролін қабылдайды; жаңа аккаунт тек осы мұғалімнің сыныбына қосылады. Мұғалімнің сессиясы өзгермейді.

`firestore.rules` жаңартылды: мұғалімдер өзін тіркей алады, бірақ тек өз сыныбына рұқсат алады; дайын аккаунттың рөлі мен мұғалім байланысын клиент өзгерте алмайды. Бұрынғы v4.0 ережесін Console-да қайта Publish ету қажет.

**Қосу нұсқаулығы: [firebase/SETUP.md](firebase/SETUP.md).** Firebase Authentication-та Email/Password және `(default)` Firestore базасы қосулы болуы керек. Нақты Console баптауларын жоба иесі орындайды, web config әкімшілік рұқсат бермейді.

Төмендегі v3/v4.0 бөлімдері тарихи сипаттама; қазіргі тіркелу ағыны осы v4.1 бөліміне сәйкес.

Қазақша жұмыс нұсқасы: қызығушылық диагностикасы → бағыт → ғылыми жоба тақырыбы → виртуалды прототип → тәжірибе және талдау → мұғалімнің бағасы мен кері байланысы.

## Алты зертхана

- **3D модельдеу:** куб, шар, цилиндр қосу; үш өлшем, координата, Y бұрышы, түс; көріністі айналдыру; OBJ экспорт. Қабаттасқан көлемді шегеру, CAD және физика жоқ.
- **Веб-дизайн:** HTML/CSS редакторы, қауіпсіз iframe көрінісі, 320/768/1200 px; HTML экспорт. Алдын ала қарауда скрипт пен сыртқы желі өшірулі.
- **Роботтехника:** 8×8 тор, кедергілерді қосу, командалар реті, қадамдап қозғалыс, қадам/бұрылыс/соқтығысу, сынақ тарихы. Нақты құрылғыға қосылмайды.
- **Бағдарламалау:** set/add/multiply/print визуалды блоктары, орындалу трассасы, күтілетін нәтижемен тест, Python файлын экспорттау. Еркін Python интерпретаторы емес.
- **Анимация:** екі кілттік кадр, координата, ұзақтық, 6/12/24/30 кадр/с, easing, таймлайн; HTML/SVG анимация экспорты. Экспорт үздіксіз векторлық қозғалыс береді.
- **ЖИ:** екі класты нүктелер, kNN (k=1/3/5), стратификацияланған бөлек тест, шынайы есептелген дәлдік пен қате матрицасы, көршілермен түсіндіру. Чатбот немесе LLM қосылмаған.

## Диагностика және жоба

12 қызығушылық сұрағы мен 6 білім тапсырмасы бөлек есептеледі. Бұл валидтелген дарындылық тесті емес. Қызығушылық тең болса, бағыттарды тең мүмкіндік ретінде қарастыру керек. Оқушы бағытын өзгерте алады.

24 тақырыпта зерттеу сұрағы, өлшем, әдіс, уақыт және қолда бар құралға сәйкестік бар. Ұсыныс ұпайы ашық формуламен есептеледі; ғылыми жаңалықты немесе конкурс сәйкестігін растамайды. Тақырыптардың көбі — зертханада бастапқы прототип жасауға болатын шағын мектеп зерттеуі; толық өнім үшін қосымша әзірлеу қажет болуы мүмкін.

Қосымша: 10 бөлімді зерттеу мәтіні, зерттеу күнделігі, бірліктер бойынша бөлек орташа мән, прототипті сақтау, экспорт, 4×5 баллдық рубрика, екіжақты пікір алмасу.

## Аккаунттар

1. Толық нұсқада сайт иесі ChatGPT аккаунтымен ашып, **Мұғалім → Жаңа аккаунт құру** арқылы өз логині мен құпиясөзін жасайды.
2. Мұғалім панелінен сынып кодын алады.
3. Оқушы **Оқушы → Жаңа аккаунт құру** бөлімінде сол кодты енгізіп, өзінің логині мен құпиясөзін жасайды.
4. Оқушы диагностикадан өтіп, жобасын сақтап, мұғалімге жібереді. Мұғалім дашбордтан қарап, бағалайды.

Платформаның бұрынғы сыртқы қолжетімділік саясаты сақталған. Егер Site иесіне ғана ашық болса, оқушыларды шақыру немесе аудиториясын ашу — бөлек баптау. Оны бұл өзгеріс автоматты өзгертпейді. Статикалық GitHub Pages демосында ортақ серверлік дерек пен қорғалған аккаунт жоқ; ол мұқият белгіленген.

Құпиясөздер PBKDF2-SHA256 (100000), жеке salt арқылы хэштеледі. Сессия HttpOnly/Secure/SameSite cookie-де, серверде токен хэші сақталады. Рөлдер мен мұғалім–оқушы байланысы әр API операциясында тексеріледі. Кіру әрекеті шектелген, жазу операциялары origin-ді тексереді. Аккаунтты қалпына келтіру мен мектептік SSO бұл нұсқада жоқ. Нақты сыныпты кең ауқымда қоспас бұрын мектептің дерек тәртібімен келісу керек.

## Құрылым және тексеру

- `web/`: клиенттің дерегі, интерфейсі және визуалды зертханалар.
- `worker/api.js`: аккаунт, рөл, жоба, мониторинг, кері байланыс API.
- `drizzle/`: D1 схема миграциясы.
- `scripts/build.mjs`: тәуелділіксіз HTML және бір ESM Worker құрастыру.
- `tests/platform.test.mjs`: нақты in-memory SQLite арқылы API ағыны, рөлдер, сақтаудың нұсқа қайшылығы, пікір, пароль хэші; есептеу, диагностика, геометрия, робот, блоктар, анимация және ЖИ бөлек тесті.

Node 24: `npm test`, `npm run build`. Браузер құралы қолжетімсіз болғандықтан визуалды браузер тексеруі орындалмады; логика мен API тексерілді. Серверлік жариялауда `.openai/hosting.json` D1 binding `DB`, миграциялар және `TEACHER_SETUP_EMAIL` серверлік айнымалысы қажет. Айнымалы мәні репозиторийге жазылмайды. GitHub Pages тек `index.html` демосын көрсетеді.

## Ғылыми жоба маршруты · v5.0 · 07.11.2026

Жеті кезең: бастапқы сынып/қызығушылық және диагностика → конкурс пен ереже → тақырыпты мақұлдау → конкурс редакторы → автоматты/мұғалім тексеруі → бағалау мен түзету → DOCX.

Бұрынғы алты зертхана, 24 цифрлық тақырып, профильдер, оқушыларды мұғалімнің тіркеуі, тәжірибелер және ескі `work.fields` өзгеріссіз оқылады. Жаңа мәтін `work.science` ішінде бөлек сақталады. 2–4 сыныптың диагностикасы жеңілдетілген; зерттеу сыныбы `work.science.grade` өрісінде сақталады, бұрынғы профиль схемасын өзгертпейді.

`web/contest-data.js` талаптың дереккөзі мен жылын бөлек сақтайды. Зерде: пайдаланушы тіркеген `Zerdekz.pdf`, №153 (09.09.2026), ресми көшірме https://daryn.kz/pol514/Zerdekz.pdf. Дарын: https://daryn.kz/kk/rknp-kz/ және сол беттен ашылған https://daryn.kz/pol514/99_rgjlk_ru.pdf. Ресми ақпараттық бет пен PDF арасындағы сынып/маусым айырмашылықтары UI-де көрсетілген. Ресми балл кестесі табылмаған жағдайда Дарын үшін ойдан балл қойылмайды: мұғалім дереккөз және жылымен кесте енгізеді.

### Деректер және құқықтар

Белсенді провайдер — Firebase Authentication және Firestore REST (`qabiletlab`). D1 бұрынғы API үшін сақталған. Қолданыстағы Firestore `users`, `classes`, `profiles`, `work`, `feedback` жинақтары пайдаланылады; жаңа жинақ не ашық ереже қажет емес.

Тақырып мақұлдауы, бөлімдік пікір, ресми рубрика және бағалау — `feedback` ішіндегі `QL_SCIENCE_V1:` оқиғалары. Шешім тек жазбаның дерекқор қорғаған `authorRole === teacher` мәнінен оқылады. Оқушының `work` ішіне жазған «мақұлданды» не рубрикасы есепке алынбайды. Қолданыстағы ереже мұғалімді өз оқушыларымен шектейді, рөл/teacherId өзгертуді және feedback жаңарту/өшіруді тыйады.

Айқын сақтау мен жіберу кезінде толық snapshot 2200 таңбалық бөліктерге бөлінеді. Жоба жаңартуы мен snapshot-тар бір Firestore commit ішінде, нұсқа precondition-ымен жазылады. Бағалау жіберілген snapshot-қа байланады. Автосақтау әр терілген таңбаны тарихқа қоспайды; соңғы жоба нұсқасын сақтайды. Толық checkpoint-терді JSON ретінде жүктеуге болады. Ірі snapshot-тар мұғалім roster сұранысын өсіреді; өскен сыныптарда бөлек беттелетін тарих жинағына көшу жоспарлануы тиіс.

### Экспорт және шектеулер

DOCX сыртқы кітапхана/серверсіз OOXML ZIP ретінде жасалады: титул, жаңартылатын TOC, 14 пт Times New Roman, A4, 1.5 интервал, 3/2/2/2 см жиектер, тақырыптар, кестелер, суреттер, күнделік, енгізілген қосымша мәтіндер. Зерде үшін қазыларға арналған титулда жеке дерек өрістері шығарылмайды. Еркін мәтін мен суреттегі жеке мәліметті мұғалім тексереді. TOC Word-та F9 арқылы жаңартылады. Дарынның тексерілген PDF-інде қаріп/жиек анықталмаған: қолданылған стиль мектептің жұмыс үлгісі ретінде көрсетілген.

Суреттер JPEG/PNG түрінде кішірейтіліп енгізіледі: бір суретке 60000 base64 таңба, барлығына 220000 таңба, ең көбі 8 сурет. Firestore құжатының бұрынғы көлем шегі сақталған. Қол қойылған PDF түпнұсқаларын кірістіретін файл қоймасы бұл нұсқада жоқ; қосымшаның мәтіні мен есеп реквизиттері экспортталады, түпнұсқа құжатты мұғалім бөлек салыстырады.

Кеңесші нақты тексеру тізіміне сүйенетін автоматты нұсқаулық береді және ЖИ-ге қауіпсіз сұрау дайындайды. Сыртқы генеративті ЖИ сервисі/API кілті қосылмаған, ол ЖИ қызметі ретінде көрсетілмейді. Деректер, нәтижелер және сілтемелер автоматты ойлап шығарылмайды.

### Тексеру жағдайы

`npm test`: бұрынғы регрессиялар, Firebase mock ағындары, жеті бет, жас санаты, конкурс сәйкестігі, студенттің мақұлдау/рубрика жалған жасауын елемеу, нақты түзету тізімі, сақтау–жіберу–қайтару–қайта жіберу, snapshot тұтастығы, қауіпті URL/сурет пішімі, DOCX. DOCX XML/ZIP және python-docx арқылы ашылуы, LibreOffice-пен PDF-ке конвертациясы тексерілген. Үлгі деректер тек тесттерде, шынайы оқушы дерегі ретінде ұсынылмайды.

Бұл ортада Sites браузерін басқарудың қажетті `cua_repl.js`/preview жолы қолжетімсіз: нақты телефон/компьютер браузерінде толық қабылдау тесті жасалмады. Firebase әкімші сессиясы жоқ: қолданыстағы live Firestore Rules алынған/қайта жарияланған жоқ; репозиторийдегі құқықтар мен adapter тексерілді, live рұқсат тесті бөлек қажет. Жаңа маршрут бұрынғы қорғалған жинақ схемасына сүйенеді.

## Кезең реті және жеке хабарламалар · 08.11.2026

Навигация: 1) тіркелу/диагностика, 2) тақырып таңдау кестесі, 3) конкурс/ережелер, 4) жоба мәтіні, 5) жұмыс жолы, 6) талаптарды тексеру, 7) мұғалім кері байланысы, 8) DOCX. Тақырыпты конкурсқа дейін таңдап/сақтауға болады. Мақұлдауға жіберер алдында конкурс пен секция міндетті түрде нақтыланады.

Оқушы мен мұғалімде жеке «Хабарламалар» беті бар. Мұғалім өз сыныбындағы оқушыны таңдайды. Мәтіндер бұрынғы қорғалған feedback жинағында, оқылғаны туралы белгілер рөлмен қорғалған readReceipt оқиғаларында сақталады. Ашық сөйлесу әр 15 секунд сайын жаңарады; мәтін енгізу өрісі жаңарту кезінде ауыстырылмайды. Хат жіберілмесе, қате көрсетіліп, енгізілген мәтін қалады. Бұл фондық push/email хабарламасы емес; сөйлесу бетін ашып оқу қажет. Жаңа Firestore жинағы/ережесі қажет емес. Нақты live Firebase рұқсаттары бұрынғыдай әкімші тексеруін қажет етеді.

Тренажер бұрынғы жеке «Виртуалды зертхана» (`#labs`) орнында қалады. «Менің жұмыс жолым» жобаның барысын көрсетеді; зертханалардың коды мен жұмысы өзгертілмейді.

## Профильден логин өзгерту · 11.11.2026

Оқушы және мұғалім профилінде бөлек «Логинді өзгерту» формасы бар: жаңа логин (3–32 таңба, латын әрпі/сан/`._-`) және қазіргі құпиясөз. Құпиясөз тек растау сұранысына жіберіліп, профильде/сессия қоймасында сақталмайды. Әрекет тек кірген аккаунтқа қолданылады; сұраныстағы бөгде id/role есепке алынбайды. UID, classCode, teacherId, жобалар мен оқушылар өзгермейді. Демо режимде батырма өшірулі.

Firebase ағыны: signInWithPassword арқылы қайта растау → accounts:update арқылы email-логинді ауыстыру → жаңа токенмен accounts:lookup → сол users/{uid} құжатындағы email-ді updateTime шартымен синхрондау. Auth сәтті, Firestore сәтсіз болса, интерфейс логиннің өзгергенін нақты айтып, жаңа логинмен қайта кіруді ұсынады; current() кезінде синхрондау қайта орындалады. Қолданыстағы Firestore validUser ережесі email-ді жаңа token.email мәнімен салыстырады; ереже әлсіретілмейді. D1 API-де қазіргі құпиясөз тексеріліп, тек өз users жолының username өрісі атомарлы жаңартылады.

Маңызды орналастыру шектеуі: Firebase email enumeration protection қосылғанда email-ді клиенттен алдын ала растаусыз ауыстыруға тыйым салады (EMAIL_CHANGE_NEEDS_VERIFICATION / OPERATION_NOT_ALLOWED). Платформа логиндері `.invalid` қызметтік email-деріне негізделгендіктен, поштаға растау хатын жеткізу мүмкін емес. Бұл жағдайда форма тыйымның себебін көрсетеді және өзгеріс сәтті болды деп мәлімдемейді; әкімші арқылы ауыстыру немесе бөлек әкімші серверін қосу керек. Бұл жұмыста live ali12 аккаунты gbm болып өзгертілген жоқ. Қорғанысты өшіру ұсынылмайды. Ресми сипаттама: https://docs.cloud.google.com/identity-platform/docs/reference/rest/v1/accounts/update .

Тесттер: қайта растау, UID/сынып/оқушы байланысының сақталуы, ескі логиннің тоқтауы, жаңа логин мен бұрынғы құпиясөзбен кіру, бос емес/қате логин, Firebase verification policy тыйымы, Auth өзгеріп Firestore істемегеннен кейін қайта кіруде қалпына келу, D1 растауы. Нақты ali12 аккаунтының құпиясөзі берілмегендіктен және әкімші сессиясы болмағандықтан, live rename тексерілген жоқ.

Хабарламаларда, кері байланыс пікірлерінде және бағалау тарихының карточкаларында күн/уақыт көрсетілмейді. Сақталған timestamp-тар хабарламалардың ретін сақтау үшін қолданылады; зерттеу күнделігінің күндері өзгертілмейді.

«Хабарламалар» жеке навигациясы мен беті алынып тасталды. Қолданыстағы хаттар жойылмайды: оқушы оларды «Мұғалімнің кері байланысы» бөлімінде, мұғалім таңдаған оқушысының «Жобаны бағалау» бетіндегі кері байланыс панелінде оқып, жауап бере алады. Ескі #messages сілтемесі сәйкес кері байланыс бетіне бағытталады.

Оқушының төменгі мәзірінен «Тәжірибе және күнделік», «Алты зерттеу бағыты», «Портфолио» тармақтары алынды; сол блокта «Профиль» қалады. Жобадағы тәжірибе/күнделікке ішкі сілтемелер жұмысын жалғастырады.


## Оқушыларды мұғалім қосатын кіру тәртібі · 12.11.2026

Басты бет, кіру формасы және қонақ зертханаларындағы өздігінен тіркелу әрекеттері алынды. Ескі `#register` сілтемесі `#login` бетіне өтеді. Бірінші кезең «Бастапқы диагностика» деп аталады, диагностика мен зертханалар сақталды. Мұғалім «Оқушыларды қосу» бөлімінен жеке логин/құпиясөз береді. FirebaseStore-дың жария register маршруты 403 қайтарады, ішкі тіркеу helper-і мұғалімнің create-student ағынында ғана пайдаланылады. D1 API-де оқушының жария тіркелуі жабық, teacher-only create-student маршруты қосылды. Бұрынғы сайт иесіне арналған D1 мұғалім bootstrap API-і сақталды, жария UI жоқ.

Қолданыстағы Firebase/Firestore ережелері өзгертілмеді: жаңа live әкімші конфигурациясы жарияланған жоқ. Осы өзгеріс платформаның жария интерфейсі мен қолданба API-іне қатысты, Firebase провайдерінде Auth signUp толық өшірілгені туралы мәлімдеме жасалмайды. Мұғалім аккаунтының сессиясы оқушы қосу кезінде сақталады. Оқушы өз логинімен кіреді, сыныбы мен қызығушылығын бастапқы диагностикада көрсетеді. Аккаунт құру, рөл/сыныпты сұраныста ауыстыруға қарсы қорғаныс, қайталанатын логин, ескі сілтемелер және барлық зерттеу кезеңдері mock/in-memory тесттермен тексеріледі. Нақты Firebase аккаунтымен қосу/кіру әкімші деректері жоқ болғандықтан тексерілмейді.
