# QabiletLab — информатика

Оқушы информатикадағы қабілетін зерттеп, сол жерде жаттығып, ғылыми жобаға дайындалатын қазақша прототип (5–9-сынып).

## Оқу жолы

1. Алгоритмдер, Python және IT-зерттеу бойынша 9 диагностикалық тапсырма.
2. Нәтиже мен қызығушылыққа сай жеке бағыт; мұғалім бағытты өзгерте алады.
3. Үш бағыттағы 9 сабақ: түсіндірме, мысал, тексеру тапсырмасы.
4. Бес интерактивті тренажер: кодты қадағалау, қатені түзету, алгоритм қадамдарын реттеу, екілік сандар, көпіршікпен сұрыптау.
5. Информатикадан ғылыми жоба: мәселе, сұрақ, болжам, әдіс, прототип, тест, нақты нәтиже, қорытынды, дереккөздер және авторлық үлес.
6. Портфолио, мұғалім бақылауы, JSON/CSV/мәтін экспорты, басып шығару.

Тренажерлар оқу логикасын браузерде орындайды. Еркін Python кодын орындау ортасы қосылмаған. Қатені түзету тренажері берілген жаттығулардың күтілетін өрнегін тексереді; жалпы Python интерпретаторы емес.

## Іске қосу

`index.html` файлын браузерде ашыңыз. GitHub Pages жариялауы `.github/workflows/pages.yml` арқылы орындалады.

## Деректер және шектеулер

Жұмыс браузердің localStorage жадында сақталады; ортақ сынып базасы, аккаунт және құрылғылар арасында синхрондау жоқ. Мұғалім бөлімі осы браузердегі бір оқушының жұмысын көрсетеді. Браузерді тазаламас бұрын портфолионы жүктеп алыңыз. Информатика нұсқасының деректері бұрынғы жалпы нұсқадан бөлек кілтте сақталады; бұрынғы дерек жойылмайды.

Диагностика бастапқы бағдар береді; валидтелген психологиялық тест емес. Әр бағытта үш сұрақ қана бар. Бірдей тапсырмалармен қайталауға есте сақтау әсер етуі мүмкін. Барлық сыныпқа ортақ тапсырмалар ұсынылады.

## Тексеру

Есептеу, тең нәтиже, мұғалім таңдауы, сақтау, мәтінді қауіпсіз көрсету, беттер, бес тренажер, сұрыптау нәтижесі мен салыстыру саны, код өрнектерін тексеру және IT-жоба құрылымы тексерілді. Бұл ортада браузер құралы қолжетімсіз болғандықтан визуалды браузер тексерісі орындалмады.
