# QabiletLab

Қабілетті зерттеу және жеке оқу бағыты арқылы дамытуға арналған қазақша прототип. 5–9-сыныптарға арналған бастапқы материалдар.

## Жұмыс істейтін мүмкіндіктер

- Үш бағыт бойынша 9 диагностикалық тапсырма, жауаптарды талдау, нәтижелер тарихы.
- Дұрыс жауап саны және қызығушылық бойынша жеке бағыт ұсыну.
- 9 сабақ: түсіндірме, мысал, тексеру тапсырмасы және кері байланыс.
- Мұғалімнің бақылау жазбасы мен оқу бағытын қолмен белгілеуі.
- Алты бөлімнен тұратын жоба шеберханасы, автоматты сақтау.
- Портфолио, басып шығару, JSON, CSV және мәтіндік экспорт.
- Телефонға бейімделген интерфейс; сыртқы кітапханаларсыз жұмыс істейді.

## Іске қосу

`index.html` файлын браузерде ашыңыз. GitHub Actions workflow GitHub Pages жариялауын орындайды. Егер Pages автоматты қосылмаса: Settings → Pages → Source → GitHub Actions таңдаңыз.

## Прототиптің шегі

Деректер тек браузердің localStorage жадында сақталады. Ортақ дерекқор, тіркелу, мұғалімнің қорғалған аккаунты және құрылғылар арасында синхрондау қосылмаған. Мұғалім бөлімі осы құрылғыдағы бір оқушының жұмысын көрсетеді. Браузер деректерін тазаламас бұрын портфолионы жүктеп алыңыз.

Диагностика — тек бастапқы бағдар. Ол валидтелген психологиялық тест емес және дарындылық туралы түпкілікті шешім шығармайды. Үш сұрақтан алынған пайыз шығармашылықтың толық бағасы емес. Барлық сыныпқа ортақ тапсырмалар беріледі. Қайта диагностикада сол сұрақтар қолданылады; нәтижені есте сақтау әсері болуы мүмкін.

## Тексеру

Есептеу логикасы жергілікті тексерілді: есептеу, бағыт ұсыну, тең нәтижені шешу, мұғалім таңдауы, мәтін қауіпсіздігі, сақтау және беттерді қалыптастыру тексерістері. Браузерде визуалды тексеру орындалмады: осы ортада браузер құралы қолжетімсіз.
